# Progress Log

Log entries as things are tried. Doesn't need to be daily or long — a few words is
enough. The point is to be able to look back after a few weeks and see what
actually correlates with better/worse days.

## Template

```
### YYYY-MM-DD

- Morning numbness (0–10): 
- Computer-heavy day? (y/n, ~hours):
- Exercises done today:
- Ergonomics/night changes in place:
- Notes (anything that stood out — better, worse, new triggers):
```
